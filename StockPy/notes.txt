15) Final practical ruleset — TL;DR (pin this)

Trade only liquid Nifty 50 names.

Keep portfolio to 2–4 active swing positions (start with 2–3).

Risk 0.5–1% per trade. Use ATR for stop calculation.

Entry only on defined setups (pullback/volume breakout/range bounce).

Max allocation per stock 10–20% of capital.

Use partial profit-taking and trailing stops.

Log every trade and respect your stops.

Overview

The program runs a daily pipeline:

Market Pre-Flight (Nifty 50 daily) → if pass, then

Universe Filter (Nifty 50 membership, liquidity, event checks) → then

Indicator calculations (50EMA, 200EMA, ATR14, ADX14, volume ADTV20) → then

Setup detection (Pullback to 50EMA + confirmation) → then

Sizing, risk checks, sector/correlation checks → then

Emit actionable signal JSON (entry/stop/targets/size) or no-signal.

Global parameters (defaults — make all tunable)

timeframe_primary = Daily

timeframe_confirm = 4H (optional)

market_preflight_EMA_short = 50

market_preflight_EMA_long = 200

stock_EMA_short = 50

stock_EMA_long = 200

atr_length = 14

adx_length = 14

adx_threshold = 25

atr_stop_multiplier = 1.5

reward_r = 2.0 (primary target = 2R)

partial_take_at_r = 2.0

trail_at_r = 2.0 (start trailing after 2R)

max_position_allocation_pct = 20% (of portfolio)

risk_per_trade_pct = 1.0% (of portfolio; allow 0.5–1.0)

max_active_positions = 3 (recommend 2–4)

adtv_days = 20

adtv_min_inr = 50_00_00_000 (₹50 Crore expressed in paise/units — programmatically: 50_00_00_000)

pullback_threshold_pct = <= 1.5% (price should be within 1.5% of 50EMA) or within <= 1 × ATR of 50EMA (use OR or AND as desired)

no_event_window_days = 3 (filter out earnings / corporate action within next 3 trading days)

sector_max_same = 2

Data Inputs Required

Daily OHLCV for Nifty 50 and each stock (adjusted close for corporate actions)

Intraday 4H OHLCV if confirm timeframe used

Corporate calendar (earnings, dividend record dates, buybacks)

Stock metadata (sector, F&O eligibility, free-float, Nifty membership)

ADTV computation window (20 trading days)

Market Pre-Flight (function: market_preflight)

Rules (must pass both):

Nifty50_price_today > EMA(Nifty50, 50) (price = daily close)

EMA(Nifty50, 50) > EMA(Nifty50, 200)

If either is false → return Market = NO_GO (no new longs).

Universe Filter (function: universe_filter(stock))

A stock is eligible only if ALL true:

is_nifty50_member == True

ADTV(20) >= adtv_min_inr (default ₹50 Crore)

no corporate events in next no_event_window_days

price_data_complete (no missing values last 60 days)

optional: F&O eligibility == True (if you want only F&O)

Indicator Calculation (function: indicators(stock))

Compute on Daily:

EMA50 = EMA(close, 50)

EMA200 = EMA(close, 200)

ATR14 = ATR(14) (use True ATR)

ADX14 = ADX(14) (Directional Movement)

ADTV20 = average(volume * close) over 20 days (use turnover in INR or shares * close)

DistanceFromEMA50_pct = (close - EMA50)/EMA50 * 100

High-Probability Setup Detection (function: detect_pullback(stock))

Core conditions to mark a candidate:

Trend filters (must pass):

close > EMA50 AND EMA50 > EMA200 (stock-level trend)

ADX14 >= adx_threshold (≥25)

Pullback proximity (one of these must pass):

abs(close - EMA50) <= pullback_threshold_pct (default 1.5%)
OR

abs(close - EMA50) <= ATR14 (price within 1×ATR of EMA50)

Volume/Confirmation (choose one):

volume_today >= avg_volume_20 (volume >= 20-day average) — OR —

close > open AND close > prior_candle_high (bullish confirmation candle on daily)

No near-term event (already filtered in universe)

If all above true → mark setup_type = "PullbackTo50EMA" and proceed to sizing.

Entry rule (programmatic)

Primary entry: place signal to buy on next open or on close depending on your execution model.

Conservative: wait for the confirmation candle to close above prior high and then enter at next open.

Aggressive: buy at close of confirmation candle.

Include entry_price = next_open_estimate or last_close if immediate fill model.

Stop Loss and Targets

stop_price = entry_price - (atr_stop_multiplier × ATR14)

Default multiplier = 1.5

risk_per_share = entry_price - stop_price

target_price_primary = entry_price + reward_r × risk_per_share (default reward_r = 2.0)

Position Sizing (function: compute_size)

Algorithm (exact, deterministic):

portfolio_value = P (live capital)

risk_money = P × risk_per_trade_pct (e.g., 1% → 0.01 * P)

raw_shares = floor( risk_money / risk_per_share )

max_shares_by_alloc = floor( (max_position_allocation_pct × P) / entry_price )

shares = min(raw_shares, max_shares_by_alloc)

If shares == 0 → skip signal (risk too large or allocation too small)

actual_risk_money = shares × risk_per_share

Ensure actual_risk_money <= risk_money (guaranteed by min). If you want exact risk, you may reduce shares by 1 until condition is true.

Round shares to exchange lot size if required.

Return: shares, position_value, actual_risk_money, risk_pct_of_portfolio.

Sector/Correlation & Portfolio Risk Check (function: portfolio_checks)

Before emitting signal:

If active_positions >= max_active_positions → reject or queue with priority.

If count_positions_in_sector(sector) >= sector_max_same → reject

Estimate worst-case simultaneous stop impact: sum_of_all_actual_risk_money_if_all_stops_hit. If > max_total_risk_threshold (e.g., 6% of portfolio) → reduce position or skip.

Optional: compute correlation between candidate and existing positions; if correlation too high (>0.8) reduce size.

Execution semantics

Signal generation happens after market close (end-of-day run) or intraday after 4H candle close if you use confirm timeframe.

Order placement: decide if you place market at next open or create limit orders near close price.

Stop placement: place GTC stop-loss order immediately after fill (OCO if broker supports).

Trade Management rules

On reaching partial_take_at_r (2R), auto-sell X% of position (default 50%) and move stop on remainder to breakeven + small buffer or trail by 1 × ATR.

If trade reaches trail_at_r, start trailing stop = close - ATR14 (or use high-of-day − ATR).

If price closes below EMA50 while in-position and momentum collapses (ADX < 20 on two consecutive days), consider manual exit.

Backtest & Metrics to track

Win rate, average R multiple, profit factor, max drawdown, annualized return, Sharpe, Sortino, avg holding time.

Track slippage and execution model assumptions (enter-at-close vs next-open).

Track signals rejected by allocation/portfolio checks for analysis.

Edge cases & robustness

Corporate actions: use adjusted prices for EMA/ATR. For real execution, use unadjusted intraday for order prices but adjust trend calculation for splits/dividends.

Missing ticks: if last close missing, skip.

Thin liquidity on extreme moves: if ADTV drops for 5 days or more, remove stock.

Earnings gap: if gap below stop before market open, handle via gap rules (fill is at open; realized loss may exceed calculated risk).

Pseudocode (core flow)
if not market_preflight():
    return no_signals

candidates = []
for stock in universe:
    if not universe_filter(stock): continue
    ind = indicators(stock)
    if detect_pullback(ind):
        sizing = compute_size(ind, portfolio)
        if sizing.final_shares > 0 and portfolio_checks(sizing, stock):
            signal = build_signal_json(stock, ind, sizing)
            candidates.append(signal)

# rank candidates by score (ADX, proximity to EMA50, ADTV)
emit_top_n_signals(candidates, n = max_active_positions - active_positions)

Simple scoring function (0–100) to rank candidates

ADX component: min(20, ADX - 20) * 2.5 (gives up to 50)

Proximity to EMA50: max(0, 25 - abs(distance_pct × 10)) (up to 25)

Volume score: min(25, (ADTV / adtv_min_inr) * 12.5) (up to 25)
Normalize and sum; prefer higher scores.
